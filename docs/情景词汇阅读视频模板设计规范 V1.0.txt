情景词汇阅读视频模板设计规范 V1.0
一、模板概述
1.1 模板名称
情景词汇阅读模板（Scene Vocabulary Reading Template）
1.2 模板定位
该模板用于生产英语四六级学习类短视频。
通过构建生活化、故事化的中文语境，将四六级高频词汇自然融入文本中，并通过视觉高亮和语音朗读帮助用户理解和记忆。
1.3 使用场景
适用于：
CET4 高频词学习 
CET6 高频词学习 
考研英语词汇复习 
日常英语积累 
1.4 视频特点
该模板采用：
静态图片

+

文本内容

+

重点词汇高亮

+

AI配音

+

背景音乐
组成完整视频。

3.2 文本展示规范
中文文本
作用：
承载故事内容。
要求：
语言自然 
接近日常表达 
避免机械翻译 
示例：
错误：
Leo获得一个合同。
正确：
Leo接到一份contract，
任务是前往未知的continent寻找文明遗迹。

英文词汇
展示规则：
重点词汇需要突出。
例如：
普通：
Leo接到一份
高亮：
contract
样式：
字体加粗

背景色突出

颜色区别

四、内容生成规范
4.1 输入参数
用户输入：
{
"topic":"森林探险",
"level":"CET4",
"wordCount":10,
"targetDuration":60
}
字段说明：
topic：
视频主题。
level：
四六级等级。
wordCount：
重点词汇数量。
targetDuration：
目标时长。

4.2 内容生成要求
AI需要生成：
标题
要求：
具有吸引力。
示例：
10个四六级词汇藏在一次森林探险里

情景故事
要求：
1.使用中文作为主体 
2.自然加入英文词汇 
3.保持故事连贯 
4.符合目标等级 
示例：
Leo接到一份contract，
任务是前往未知的continent寻找文明遗迹。

他与队友consult路线后出发。

重点词汇列表
格式：
[
 {
 "word":"contract",
 "meaning":"合同",
 "level":"CET4"
 }
]

五、四六级词汇处理规则
5.1 词汇来源
禁止：
AI自行创造四六级词。
必须：
通过四六级词库。
流程：
AI生成文本

↓

提取候选词

↓

四六级数据库查询

↓

确认等级

↓

替换展示

5.2 词汇要求
每条视频：
建议：
CET4：
5-10个词
CET6：
3-8个词
避免：
一次出现过多生词。

七、AI生成Prompt规范
角色定义
你是一名英语短视频内容创作者。
你的任务是制作适合抖音发布的四六级词汇学习视频。

生成要求
根据用户提供主题生成一个英语学习故事。

要求：

1. 使用中文作为主要叙述语言。

2. 自然加入指定数量四六级词汇。

3. 英文词汇必须符合上下文。

4. 故事情节简单易懂。

5. 输出结构化数据。

九、视频生成流程

说明：TTS 语音合成在上游 Dify Workflow B 的 TTS 节点独立完成，音频文件通过
ContentDTO.audio 传入。本节只描述视频渲染阶段。

输入：
  · ContentDTO（含 audio 音频文件、style 样式配置）
  · 背景音乐文件

处理流程：

ContentDTO + 背景音乐

        ↓

HTML模板渲染（根据 template 选择对应模板，注入 content + style）

        ↓

生成图片帧（Puppeteer / Playwright 截图）

        ↓

FFmpeg合成（图片帧 + audio + 背景音乐 → MP4）

        ↓

输出MP4（9:16, 1080×1920）
