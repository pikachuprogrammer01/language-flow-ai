## 三、署名要求（抖音发布合规）

- **免署名曲库（第一节）**：CC0/公有领域，**发布抖音无需署名、可商用**，零版权负担 ✅
- **CC-BY 曲库（第二节）**：发布抖音**必须署名**作者（见作品页），否则侵权；**建议发布用免署名曲库**
- 平台层面：抖音不主动审查 CC-BY；但作者可投诉下架。非商用也不能免除署名义务

## 四、重建方式（文件丢失时）

```bash
mkdir -p packages/backend/uploads/bgm
cd packages/backend/uploads/bgm
# 免署名曲目（CC0/PD）
curl -L -o free-01-emotional-piano.mp3 "https://opengameart.org/sites/default/files/untitled.mp3"
curl -L -o free-02-haunting-piano.mp3 "https://opengameart.org/sites/default/files/haunting%20piano.mp3"
curl -L -o free-03-vampires-piano.mp3 "https://opengameart.org/sites/default/files/vampires_piano_8.mp3"
```
