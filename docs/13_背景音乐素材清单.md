## 署名要求

- **Public Domain**（07）：可自由使用，无需署名
- **CC-BY**（其余 7 首）：使用需署名作者（见各作品页作者信息），建议在视频简介/文档中标注
- 本地开发使用无碍；若未来对外发布视频，需按 CC-BY 要求署名

## 重建方式（文件丢失时）

```bash
mkdir -p packages/backend/uploads/bgm
cd packages/backend/uploads/bgm
curl -L -o 01-calm-bgm.mp3 "https://opengameart.org/sites/default/files/audio_preview/041415calmbgm.ogg.mp3"
# ... 其余曲目 URL 见上表作品页内的下载链接
```
