## 一、技术栈与数据流

- Vue 3.5 Composition API + `<script setup lang="ts">` + Vue Router 4
- shadcn-vue + Tailwind CSS 4；**设计令牌**对齐后台原型（`style.css` `@theme`：品牌紫 `#6d5dfc`、页面背景 `#f6f7fb`、分割线 `#e8eaf0`、侧边栏 `#11131a` 等，工具类 `bg-brand`/`border-hairline`/`text-subtle` …）
- **UI 底座统一 reka-ui（Radix Vue 官方后继）+ lucide-vue-next**：提示类与图标不再用第三方成品库/emoji——`lib/toast.ts`（全局 toast 状态，success/error/warning/info）+ `components/ui/app-toaster.vue`（reka-ui Toast 渲染宿主，App.vue 挂一次）；`components/ui/confirm-dialog.vue`（reka-ui AlertDialog）；业务弹窗（上传标记/播放器）底座同为 reka-ui Dialog；图标统一 lucide SVG
- **跨端纯函数单一事实源**：scene_word 字号档位 `fitSceneWordFontSize` 上提 `@ai-english/shared`（`render.ts`），渲染器与手机预览同源；预览按 1080×1920 等比缩放复刻成片帧（见 3.1）
- **openapi-fetch** 类型安全客户端：`src/api/client.ts`（`pnpm --filter frontend gen-api` 从 backend `openapi.json` 生成 `schema.d.ts`）
- 列表/详情以页面内 `ref` + 主动请求为主（`@tanstack/vue-query` 已安装，未全面接入）；工作台为生命周期驱动的 500ms 轮询（见 3.0）

串联生成（新建页）：

```
POST /api/content/generate
  → POST /api/tts/from-content
  → POST /api/video/render
  →（可选）PATCH /api/tasks/:id 回写产物
```

## 二、路由与布局壳

| 路径 | 组件 | meta.title（面包屑） | 说明 |
|------|------|------|------|
| `/` | `Dashboard.vue` | 工作台 | 今日指标 + 生产流水线 + 最近任务（实时轮询） |
| `/create` | `CreateTask.vue` | 新建视频 | 主流程（步进器 + 表单 + 手机预览） |
| `/tasks` | `TaskList.vue` | 生成记录 | DataTable 表格 |
| `/tasks/:id` | `TaskDetail.vue` | 生成记录 | 详情 + 编辑 + 重配音/重渲染 |
| `/files` | `Files.vue` | 文件管理 | 分组表格（主题列 rowspan） |
| `/videos` | `VideoList.vue` | 视频资产 | 9:16 资产卡片（第一帧预览） |
| `/marks` | `MarksList.vue` | 上传标记 | DataTable 表格 |
| `/analytics` | `Analytics.vue` | 发布管理 | 行选中联动 + 文案面板 |
| `/audit` | `AuditList.vue` | 审计管理 | DataTable + 展开审计档案 |

**布局壳（App.vue）**：1:1 还原原型 —— 238px 深色侧边栏（生产中心/内容资产/运营与系统三分组，激活项内阴影紫条）+ 68px 毛吸顶栏（面包屑跟随 `meta.title`、LLM 状态位、「＋新建视频」）。
- **响应式**：≥lg 侧边栏常驻；小屏隐藏，顶栏汉堡按钮开合抽屉（遮罩点击/路由跳转自动收起）
- **LLM 状态位（SSE 推送非轮询、非假实现）**：前端不用定时器，订阅 `GET /api/llm/stream`（SSE，`EventSource` 自带断线重连）——连接即推快照、之后仅状态变化才推，无过渡态时服务端降为 30s 低频对账（仅在有订阅者时跑）。三级判定依据 `GET /api/llm/status`（服务可达 → 模型已安装 `/v1/models` → 已加载 `/api/ps`）；四态灯：绿就绪 / 黄待机（已装未加载）/ 红不可达或未安装 / 灰未收到状态。**启动/关闭均有中间态**：`llm-engine.ts` 状态机 `phase` 为 `starting`/`stopping` 时按钮显“启动中…/关闭中…”（紫点脉冲 + tooltip 实时进度如“正在把模型加载进内存”）；**启动失败/加载超时/降级均即时提示**（`error` 红 toast / `notice` 黄 toast / 成功绿 toast）。未就绪时按钮为 **「▶ 启动 {模型名}」**点击 `POST /api/llm/wake`；就绪/待机时另露 **「⏻ 关闭」**（两段式确认防误触）点击 `POST /api/llm/sleep`。仅不支持 EventSource 环境回退 30s 探测

## 三、页面规格（摘要）

### 3.0 Dashboard.vue（工作台）

- 数据源 `GET /api/dashboard/summary` 聚合端点（后端 Promise.all 并行子查询），前端不再拉全量列表自算
- 指标卡：今日生成（含较昨日百分比）/ 待渲染（配音存量同源）/ 已完成视频（top 模板占比）/ 异常任务
- **异常卡红色标记**：`failed>0` 时整卡红边红底红字，副文案直出失败原因（后端从 `contents.audit` 最后拒绝原因 + `video.introStatus=failed` 聚合，如「片头生成失败 ×2」）
- 生产流水线 5 阶段（内容生成/词库验收/TTS 配音/视频渲染/可发布），第一个有存量阶段高亮；可发布 = 成片且无上传标记
- **真实时轮询**：仅组件存活期间运行（`onMounted` 起 / `onUnmounted` 即停），间隔 500ms；页面隐藏（`visibilityState`）跳过；单飞防重入；模块级单例 timer（防 HMR/快切残留叠加）；失败保留上一次数据；「实时状态」角标带最后同步时刻

### 3.1 CreateTask.vue

- 路由 `/create`；布局对齐原型：4 步步进器（内容设置/AI 生成/配音设置/渲染确认，由 step 状态映射）+ 左表单/右 9:16 手机预览双栏
- 手机预览实时渲染生成结果：scene_word 故事正文重点词高亮 + 底部词汇条；word_card 卡片；quiz 题干选项
- 模板：scene_word / word_card / quiz（卡片式选择 + emoji 缩略图）
- 主题：分组预设 + 自定义 + **AI 推荐**（`POST /api/topics/suggest`）；目标时长下拉（45/60/90s 透传生成服务）
- 等级 CET4/CET6；音色列表 + 试听；语速；BGM 下拉 + 试听；**观众保存策略 `allowSave` 复选框**（默认开，渲染成功后 `PATCH /api/video-analytics/:id` 落库，与发布管理/标记弹窗同源）
- scene_word 片头开关（`style.introEffect`，默认开）；完成页按 `video.introStatus` 展示片头结果徽章（图标+文字非仅颜色）
- 分步：生成内容 → 配音 → 渲染；可原地编辑后再配音/渲染（任一步失败只重试本步，成果保留）

### 3.2 TaskList.vue

- DataTable 表格（客户端分页）：标题（含正文摘要+已标记徽章）/模板/等级/状态胶囊/词汇/更新时间/操作；行点击进详情；表头全选+批量删除；搜索（标题/Content ID）+模板/标记筛选
- 操作列保留全功能：📂 Finder 打开、🏷 标记（弹窗含 allowSave）、📋 复制名称、删除

### 3.3 TaskDetail.vue

- 内容编辑（三模板编辑器）、审计折叠区、视频播放、管理标记
- scene_word 片头开关（持久化走 `PATCH /api/tasks/:id/render-settings`）+ 片头结果徽章（`video.introStatus`）
- 音色/BGM 下拉复用 `GET /api/tts/voices` / BGM 目录，当前遗留值不在目录时补不可选兜底项（不被白名单锁死）

### 3.4 Analytics.vue（发布管理）

- 左侧任务表 + 右侧详情面板；**整行任意位置点击即选中**（非仅标题列），选中行左侧品牌紫竖条 + 底色高亮，面板标题显示当前视频
- **视频文案卡片**：选中行懒加载 `GET /api/tasks/:id` 完整 DTO，按模板提取可展示文案（`lib/analytics-copy.ts` 纯函数：scene_word 正文分段 / word_card 词条行 / quiz 题干+答案+解析），缓存不重复拉
- 发布元数据：故事主题、发布时间（datetime）、封面、允许保存、自定义参数（text/image）、音色、BGM；批量 hydration（`GET /api/video-analytics?ids=`）
- 音色/BGM 为 select（选项来自 `GET /api/tts/voices` 与 BGM 目录，后端白名单兼容未变更遗留值）
- 持久化状态机（`lib/analytics-state.ts`）：idle → dirty → saving → saved | failed；防抖 400ms 自动保存，失败可见保留本地草稿可重试；本地草稿与服务端水合互斥

### 3.5 Files.vue（分组表格）

- 指标卡：视频/音频/BGM/可清理（数量+占用，真实统计）；分类 Tab（切换时清空选中与播放器）
- **主题列（第二列）分组跨行合并**：被同一生成记录引用的成片+配音聚为一组（组内视频在前），主题列 rowspan 垂直居中；音频行标注「🔗 与上方成片同源」；未引用文件各自成组显示「未引用」
- 播放/试听改为**弹窗**（radix Dialog，避免与 rowspan 布局冲突）；清理未引用、批量删除、标记保留

### 3.6 Videos / Marks / Audit

- 视频资产：9:16 渐变卡片网格，封面为**第一帧预览**（原生 `<video preload="metadata" #t=0.1>` 截帧，失败回退渐变底），chips 含模板/等级/时长/**词数**/已标记；点击就地播放
- 上传标记一览：DataTable（视频/平台/链接/备注/创建时间/操作），`GET /api/upload-marks/overview`
- 审计：DataTable 服务端分页（每页条数可选），搜索、行展开审计档案（`audit-detail.vue` 懒加载）、批量删除

### 3.7 DataTable 统一表格组件（全站列表强制使用）

- `components/ui/data-table.vue`：泛型受控展示组件（零内部状态，page/selected/expanded 全由页面持有），列插槽 `#cell-<key>`、`#expand` 展开行、`activeKey` 持续高亮、行点击
- 能力：分页（页码窗口 + **上/下一页** + 每页条数 10/20/50/100）、勾选列+当前页全选、分组列 rowspan 合并（`groupKey` + 列 `group:true`）
- 双分页模式：传 `total` = 服务端分页；不传 = 客户端切片
- 纯逻辑收敛 `lib/data-table.ts`（immutable 无副作用，有单测）；状态映射/相对时间在 `lib/status.ts`；旧行组件（task-row/file-row/audit-row/pagination）已退役删除

## 四、主要后端 API（前端已用）

| 方法/路径 | 用途 |
|-----------|------|
| POST /api/content/generate | AI 生成 ContentDTO |
| POST /api/tts/from-content · GET /api/tts/voices | 配音 / 音色列表 |
| POST /api/video/render | 渲染 MP4（可带 BGM） |
| GET/PATCH/DELETE /api/tasks · POST batch-delete | 生成记录 |
| GET /api/video-analytics · GET/PATCH /api/video-analytics/:contentId | 视频分析元数据与批量查询 |
| PATCH /api/tasks/:id/render-settings | 持久化片头动效设置 |
| GET/DELETE /api/files* · POST /api/files/reveal | 文件与 Finder 定位 |
| GET/POST/PATCH/DELETE /api/upload-marks · GET …/overview | 上传标记 |
| POST /api/topics/suggest | 主题推荐 |
| GET /api/dashboard/summary | 工作台实时聚合（指标/流水线/失败原因/最近任务） |
| GET /api/llm/status · GET /api/llm/stream · POST /api/llm/wake · POST /api/llm/sleep | LLM 三级探测 / SSE 状态事件流（含启停过渡态与失败提示）/ 一键启动 / 一键关闭 |

契约以运行时 `openapi.json` / `/doc` 为准。

## 五、组件划分（现状）

```
components/
├── ui/                 # data-table / status-pill / button / spinner / confirm-dialog …
├── editors/            # segment / card / quiz / word-chips
├── audit-detail.vue    # 审计档案展开面板（DataTable #expand 内容）
├── audit-panel.vue     # 详情页生成档案（TaskDetail 使用）
└── upload-mark-manager.vue  # 标记弹窗（含 allowSave 保存策略，taskId 存在时展示）
lib/
├── data-table.ts       # 分页/选择集/分组 rowspan 纯函数（有单测）
├── status.ts           # 状态胶囊变体/中文标签/模板标签/相对时间
├── analytics-copy.ts   # 发布管理视频文案提取纯函数
└── analytics-state.ts  # 发布元数据持久化状态机
```

已退役删除：`task-row.vue` / `file-row.vue` / `audit-row.vue` / `ui/pagination.vue`（全部由 DataTable 取代）。
视频播放：资产页卡片就地内嵌 `<video>`，文件管理页为 Dialog 弹窗；均无独立 VideoPlayer 组件。
