## 一、技术栈与数据流

- Vue 3.5 Composition API + `<script setup lang="ts">` + Vue Router 4
- shadcn-vue + Tailwind CSS 4
- **openapi-fetch** 类型安全客户端：`src/api/client.ts`（`pnpm --filter frontend gen-api` 从 backend `openapi.json` 生成 `schema.d.ts`）
- 列表/详情以页面内 `ref` + 主动请求为主（`@tanstack/vue-query` 已安装，未全面接入）

串联生成（新建页）：

```
POST /api/content/generate
  → POST /api/tts/from-content
  → POST /api/video/render
  →（可选）PATCH /api/tasks/:id 回写产物
```

| 路径 | 组件 | 说明 |

## 三、页面规格（摘要）

### 3.1 CreateTask.vue

- 模板：scene_word / word_card / quiz
- 主题：分组预设 + 自定义 + **AI 推荐**（`POST /api/topics/suggest`）
- 等级 CET4/CET6；音色列表 + 试听；语速；BGM 下拉（默认可选钢琴曲）
- 分步：生成内容 → 配音 → 渲染；可原地编辑后再配音/渲染

### 3.2 TaskList.vue

- 模板分类 tab + 已标记/未标记过滤；批量删除；📂 打开（Finder reveal）；🏷 标记

### 3.3 TaskDetail.vue

- 内容编辑（三模板编辑器）、审计折叠区、视频播放、管理标记

### 3.4 Files / Videos / Marks / Audit

- 文件：分类列表、删除、清理未引用、标记
- 视频资产：播放、标记、删除（关联记录）
- 上传标记一览：`GET /api/upload-marks/overview`（链接/平台/备注/时间/视频信息）
- 审计：搜索、分页、行展开档案、批量删除

## 四、主要后端 API（前端已用）

| 方法/路径 | 用途 |
|-----------|------|
| POST /api/content/generate | AI 生成 ContentDTO |
| POST /api/tts/from-content · GET /api/tts/voices | 配音 / 音色列表 |
| POST /api/video/render | 渲染 MP4（可带 BGM） |
| GET/PATCH/DELETE /api/tasks · POST batch-delete | 生成记录 |
| GET/DELETE /api/files* · POST /api/files/reveal | 文件与 Finder 定位 |
| GET/POST/PATCH/DELETE /api/upload-marks · GET …/overview | 上传标记 |
| POST /api/topics/suggest | 主题推荐 |

契约以运行时 `openapi.json` / `/doc` 为准。
