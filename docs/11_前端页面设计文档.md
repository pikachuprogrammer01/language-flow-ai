## 一、技术栈与数据流

- Vue 3.5 Composition API + `<script setup lang="ts">` + Vue Router 4
- shadcn-vue + Tailwind CSS 4（`components.json` 已配置）
- **openapi-fetch** 类型安全客户端（禁 axios/裸 fetch）：`src/api/client.ts` 封装
- **openapi-typescript**：`pnpm --filter frontend gen-api` 从 `openapi.json` 生成 `src/api/schema.d.ts`
- **TanStack Vue Query**（已装）：列表/详情缓存、状态轮询（视频渲染进度）
- 状态管理：Pinia（已装，当前页面少可先不用，需要时再加）

## 三、页面规格

### 3.1 CreateTask.vue（新建任务）

**表单字段**（对应 `CreateContentRequest`，见 shared/request.dto.ts）：

| 字段 | 控件 | 必填 | 默认 | 约束 |
|------|------|------|------|------|
| template | shadcn 单选卡片（3 模板带示意图） | ✅ | - | scene_word / word_card / quiz |
| topic | Input + 预设主题 chips + AI 推荐（PRD §10.1.2） | ✅（scene_word） | 森林探险 | 主题文案 |
| level | Select | ✅ | CET4 | CET4 / CET6 |
| voice | Select + 🔊 试听（固定试听文本合成播放，PRD §10.1.1） | 否 | zh-CN-XiaoxiaoNeural | 晓晓/云希… 8 音色 |
| style | 隐藏（当前固定 `{ background: "white" }`） | 否 | white | 背景图方案扩展后再做选择器 |

> 2026-08-17：wordCount / targetDuration 表单已删除（内容生成由代码按主题自动定词数与时长，见 docs/15）

**交互**：
1. 提交 → `POST /api/contents`（创建任务，返回 `id`）
2. 创建成功后跳转 `/detail/:id`，详情页触发生成流程
3. 校验失败：表单内联错误提示

### 3.2 TaskList.vue（任务列表）

- 表格列：标题 / 模板 / 等级 / 词数 / 状态（badge）/ 创建时间 / 操作（查看）
- 状态筛选（8 状态）+ 分页（`PaginatedResponse`，page/pageSize）
- 查询：`GET /api/contents?page=&pageSize=&status=`
- 状态 badge 配色约定：

| 状态 | 颜色 |
|------|------|
| draft / ai_generating / tts_processing / video_rendering | 蓝（进行中） |
| content_ready / audio_ready | 黄（待下一步） |
| completed | 绿 |
| failed | 红 |

### 3.3 TaskDetail.vue（任务详情）

- 顶部：标题 + 状态 badge + 操作按钮（重新生成 / 删除）
- **内容区**：按 template 渲染 ContentDTO.content：
  - scene_word：段落列表 + 高亮词 + 释义条
  - word_card：卡片网格
  - quiz：题目 + 选项 + 解析
- **音频区**：`audio.url` 存在时显示 `<audio controls>` 试听
- **视频区**：`video.url` 存在时显示 `<video controls>`（9:16 播放器）
- **轮询**：任务状态处于进行中（ai_generating/tts_processing/video_rendering）时，Vue Query `refetchInterval: 3s` 自动刷新；completed/failed 停止
- 数据：`GET /api/contents/:id`（`ContentDetail`）

## 四、前端依赖的后端 API 清单（缺口标注）

当前 SPEC §五 仅定义 cet/tts/render 三个接口，**任务 CRUD 接口尚未在 SPEC 定义**（docs/03 模块 10 只有概念）。本页面前提是以下契约（**待 SPEC §五 补充 + 后端实现**）：

| 方法/路径 | 用途 | 请求 | 响应 |
|-----------|------|------|------|
| POST /api/contents | 创建任务 | CreateContentRequest | ContentDetail |
| GET /api/contents | 列表 | page/pageSize/status | PaginatedResponse\<ContentListItem\> |
| GET /api/contents/:id | 详情 | - | ContentDetail |
| PATCH /api/contents/:id | 编辑（审核修改） | EditContentRequest | ContentDetail |
| POST /api/contents/:id/generate | 触发 Workflow A 生成 | - | 200 |
| DELETE /api/contents/:id | 删除 | - | 204 |

> 页面开发（#28-#30）依赖上述接口落地；可先用 mock 数据并行开发。
