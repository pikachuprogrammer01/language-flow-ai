## 一、目标

用户输入主题/等级 → 后端调用 LLM 生成「情景词汇阅读」内容（中文故事 + 四六级词嵌入）→
词库校验 → 返回标准 ContentDTO（scene_word 模板）。**零外部平台依赖，纯 HTTP 调用 LLM。**

## 二、接口契约

### POST /api/content/generate

请求体：

```json
{
  "topic": "森林探险",
  "level": "CET4",
  "wordCount": 8,
  "targetDuration": 60
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| topic | string | ✅ | 故事主题，≤ 50 字 |
| level | "CET4" \| "CET6" | ✅ | 四六级等级 |
| wordCount | int 3~15 | 否 | 期望词汇数（默认 8；CET6 建议 3-8） |
| targetDuration | int 15~300 | 否 | 目标视频时长（秒，影响段数建议） |

响应：

```json
{
  "content": {
    "id": "cnt_20260817_000001",
    "template": "scene_word",
    "title": "职场英语：读一个科技创业故事",
    "level": "CET4",
    "targetDuration": 60,
    "content": [
      {
        "text": "奥斯丁在一家科技establishment工作，负责equip实验室的先进设备。",
        "words": [{ "word": "establishment", "meaning": "机构", "level": "CET4" }]
      }
    ],
    "words": [],
    "style": { "background": "white" },
    "voice": { "id": "female_01" },
    "status": "content_ready",
    "createdAt": "...", "updatedAt": "..."
  }
}
```

错误：400（参数校验）/ 500（LLM 超时、JSON 解析失败、词库校验后无可用词）。

## 三、处理流程（后端 service）

```
POST /api/content/generate（Zod 校验）
  → content.service.generateSceneWord({topic, level, wordCount, targetDuration})
     1. 组装 prompt（§五规范）→ llm.service.chatCompletion()
     2. LLM 返回 JSON：{ title, segments: [{text, words:[{word, meaning}]}] }
     3. 解析 + 结构校验（zod 宽松 schema）
     4. 词汇校验：words 全部经 cet.service.validateWords 过滤——
        - 不在词库的词 → 丢弃（单词命中 < wordCount 可接受，story 保留）
        - 词义以词库 meaning 为准（LLM 的 meaning 仅参考）
     5. 组装 ContentDTO（template=scene_word, status=content_ready）
  → 返回 ContentDTO
```

**段数建议**：targetDuration ≤ 30s → 1 段；≤ 90s → 2 段；其余 3 段（每段 40-80 字）。

## 四、LLM 抽象（llm.service）

- OpenAI 兼容 Chat Completions：`POST {LLM_BASE_URL}/chat/completions`
- 环境变量（全部可选，未配置时接口返回 503 提示配置）：

| 变量 | 示例 | 说明 |
|------|------|------|
| LLM_BASE_URL | https://api.agnes-ai.com/v1 或 http://localhost:11434/v1 | 兼容端点 |
| LLM_API_KEY | sk-xxx / ollama | Agnes key；Ollama 任意值 |
| LLM_MODEL | agnes 模型 ID / qwen2.5:7b | 模型名 |

- 切换：改环境变量即可（Agnes ↔ Ollama），**代码零改动**；前端设置页（阶段 5）后续可写配置
- 超时 60s；响应非 JSON / 解析失败 → 500

## 五、Prompt 规范（scene_word 生成）

角色：英语短视频内容创作者。
要求（源自《情景词汇阅读视频模板设计规范 V1.0》§七 + 用户 2026-08-17 定稿）：

1. 中文作为主要叙述语言，四六级英文词汇**自然嵌入句中**（如"Leo接到一份contract"）
2. 词数 = wordCount（可用词从提示的四六级词表范围中选，**不得自造**）
3. 故事情节连贯、生活化，主题 = topic，等级 = level
4. 标题：**主题式**（点明主题+学习内容，自然不夸张，≤ 20 字，如"职场英语：读一个科技创业故事"）
5. 输出严格 JSON：

```json
{
  "title": "职场英语：读一个科技创业故事",
  "segments": [
    {
      "text": "奥斯丁在一家科技establishment工作。",
      "words": [{ "word": "establishment", "meaning": "机构" }]
    }
  ]
}
```

6. words 的 word 必须**逐字出现在**对应 segment 的 text 中（渲染高亮依赖）

## 六、错误处理

| 场景 | 行为 |
|------|------|
| LLM 未配置（env 缺失） | 503，提示配置 LLM_BASE_URL/LLM_API_KEY/LLM_MODEL |
| LLM 超时（>60s）/ 网络错误 | 500，可重试 |
| 返回非 JSON / 结构不符 | 500（记录原始输出便于调试） |
| 词汇全部未通过词库校验 | 500（提示词库为空或 LLM 输出不合法） |
