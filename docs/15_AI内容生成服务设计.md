## 一、目标

用户输入主题/等级 → 后端调用 LLM 生成「情景词汇阅读」内容（中文故事 + 四六级词嵌入）→
词库校验 → 返回标准 ContentDTO（scene_word 模板）。**零外部平台依赖，纯 HTTP 调用 LLM。**

## 二、接口契约

### POST /api/content/generate

请求体：

```json
{
  "topic": "森林探险",
  "level": "CET4"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| topic | string | ✅ | 故事主题，≤ 50 字 |
| level | "CET4" \| "CET6" | ✅ | 四六级等级 |

> 2026-08-17：wordCount / targetDuration 已从前端表单删除；API 字段保留。
> 未传时默认 targetDuration=60；词数由代码决定（默认约 8–16，硬下限 **8**、上限 20）。

响应：

```json
{
  "content": {
    "id": "cnt_20260817_000001",
    "template": "scene_word",
    "title": "职场英语：读一个科技创业故事",
    "level": "CET4",
    "targetDuration": 60,
    "content": [
      {
        "text": "奥斯丁在一家科技establishment工作，负责equip实验室的先进设备。",
        "words": [{ "word": "establishment", "meaning": "机构", "level": "CET4" }]
      }
    ],
    "words": [],
    "style": { "background": "white" },
    "voice": { "id": "female_01" },
    "status": "content_ready",
    "createdAt": "...", "updatedAt": "..."
  }
}
```

错误：400（参数校验）/ 500（LLM 超时、JSON 解析失败、词库校验后无可用词）。

## 三、处理流程（后端 service，V4.1）

```
POST /api/content/generate（Zod 校验）
  → content.service.generateSceneWordContent({topic, level, wordCount?, targetDuration?})
     1. 混合词表：LLM 主题相关词（词库校验）+ 词库随机抽样，补足至约 120 词
        （已删除 V3 的 NARRATIVE_WORDS 固定叙事词表）
     2. 两段式：① LLM 从词表选词 → ② 内联必用清单写纯中文故事
        （JSON：{topic, title, segments:[{text}]}；模型不负责嵌英文）
     3. extractJson + zod 结构校验
     4. 代码全池注入：按词库释义中文义项在 text 中出现 → 原位替换为英文
        （须处理词性前缀如 n./vt.；义项按长度降序）
     5. 验收：topic 回显覆盖率 + 全篇唯一英文词 ≥ 8（SCENE_MIN_WORDS_PER_CONTENT）
     6. 失败则反馈原因重试（最多 3 次，每次全新对话）
     7. 组装 ContentDTO（template=scene_word, status=content_ready）+ audit
  → 返回 ContentDTO
```

**设计动机**：qwen2.5:7b 无法可靠完成「写故事并同时标注英文词」的元任务。
V4 用混合大词表 + 两段式选词写故事 + 代码注入，验收下限由 5 提高到 **8**。

**段数建议**：targetDuration ≤ 30s → 1 段；≤ 90s → 2 段；其余 3 段。

**失败兜底**：3 次仍失败 → 500，前端可重试生成。

## 四、LLM 抽象（llm.service）

- OpenAI 兼容 Chat Completions：`POST {LLM_BASE_URL}/chat/completions`
- 环境变量（全部可选，未配置时接口返回 503 提示配置）：

| 变量 | 示例 | 说明 |
|------|------|------|
| LLM_BASE_URL | http://localhost:11434/v1 | 兼容端点（Ollama 本地；后端在 Docker 时用 host.docker.internal） |
| LLM_API_KEY | ollama | Ollama 不校验，任意值 |
| LLM_MODEL | qwen2.5:7b | 模型名 |

- 切换：改环境变量即可（换 Ollama 模型/换兼容端点），**代码零改动**；前端设置页（阶段 5）后续可写配置
- 超时 60s；响应非 JSON / 解析失败 → 500

## 五、Prompt 规范（scene_word，V4）

角色：英语短视频内容创作者。
要求：

1. **模型只写纯中文故事**（英文由代码注入）
1b. **词汇数**：验收 ≥8 且 ≤20；候选来自「主题词 + 随机补足约 120」混合池（无固定叙事死列表）
2. 情节连贯、紧扣 topic；标题主题式、≤ 20 字
3. 两段式选词后，故事须尽量覆盖必用词的中文义项原文，便于注入
4. 段数按 targetDuration 建议
5. 输出严格 JSON：`{ topic, title, segments:[{ text }] }`（不含 words 数组）

## 六、错误处理

| 场景 | 行为 |
|------|------|
| LLM 未配置（env 缺失） | 503，提示配置 LLM_BASE_URL/LLM_API_KEY/LLM_MODEL |
| LLM 超时（>60s）/ 网络错误 | 500，可重试 |
| 返回非 JSON / 结构不符 | 500（记录原始输出便于调试） |
| 词汇全部未通过词库校验 / 验收不足 8 词 | 500（含可读原因） |
