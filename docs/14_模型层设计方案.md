## 二、后端 LLM 配置（替代原 Dify 模型供应商）

### 2.1 Agnes（主力）

1. 注册 https://console.agnes-ai.com 获取 API key
2. 确认 Agnes 的 API 端点是否 **OpenAI 兼容**（`/v1/chat/completions` 格式）——注册后在控制台文档确认
3. 后端 `.env` 配置：

```bash
LLM_BASE_URL=https://api.agnes-ai.com/v1   # 以控制台文档为准
LLM_API_KEY=你的-agnes-key
LLM_MODEL=agnes-支持的模型ID
```

### 2.2 Ollama（兜底）

```bash
# 本机安装（推荐，Metal 加速）
curl -fsSL https://ollama.com/install.sh | sh   # 或 brew install ollama
ollama pull qwen2.5:7b                           # ~4.7GB，后台下载
```

后端 `.env` 配置：

```bash
LLM_BASE_URL=http://localhost:11434/v1   # 后端本机跑；后端在 Docker 时用 http://host.docker.internal:11434/v1
LLM_API_KEY=ollama                        # Ollama 不校验 key，任意值
LLM_MODEL=qwen2.5:7b
```

### 2.3 切换操作（不改代码）

| 动作 | 操作 |
|------|------|
| Agnes → Ollama | `.env` 改 `LLM_BASE_URL=http://localhost:11434/v1` + `LLM_MODEL=qwen2.5:7b`，重启后端 |
| Ollama → Agnes | 改回 Agnes 的 URL/key/model，重启后端 |
| 验证 | `POST /api/content/generate` 跑一次，看返回内容来自哪个模型 |

## 三、Docker 打包说明

| 组件 | 打包方式 | 网络 |
|------|----------|------|
| 后端（本仓库） | 现有 Dockerfile（Hono + MySQL） | 默认网络 |
| MySQL | 现有容器（8.4） | 默认网络 |
| Ollama（可选，兜底） | `ollama/ollama` 镜像 + `ollama-data` volume | 同网络，`http://ollama:11434/v1` |
| Agnes | 无需容器（纯 HTTP API），key 存环境变量 | 外网 |

compose 片段（兜底 Ollama，**随 compose 自动启动，无需手动开**）：

```yaml
  ollama:
    image: ollama/ollama
    restart: unless-stopped      # 随 Docker 自动拉起，挂了自动重启
    volumes:
      - ollama-data:/root/.ollama
    ports:
      - "11434:11434"
volumes:
  ollama-data:
```

> ⚠️ 注意：macOS Docker Desktop 容器内 Ollama **无 Metal GPU 加速**（CPU 跑 7B ≈ 8-12 tok/s）；
> 追求速度时本机装 Ollama（Metal，20-30 tok/s），后端连 `localhost:11434/v1`（本机）或 `host.docker.internal:11434/v1`（后端在 Docker）。

### 3.1 Ollama 启动方式（避免遗忘，用户确认 2026-08-17）

| 阶段 | 启动方式 | 手动操作 |
|------|----------|----------|
| **当前（本机开发）** | `nohup ollama serve > ~/ollama.log 2>&1 &`（或另开终端跑 `ollama serve`） | 每次开机后跑一次；也可 `brew services start ollama` 设开机自启，之后不用管 |
| **后期（全容器化）** | `docker compose up -d`，ollama 容器随 compose **自动启动**（`restart: unless-stopped`） | **无需手动开 ollama**，模型存 `ollama-data` volume，pull 一次永久有效 |
| **后期（本机 ollama + 容器其他）** | `brew services start ollama` 开机自启 | 无需手动操作（后端连 `host.docker.internal:11434/v1`） |

> 决策：用户更在意速度 → 当前用本机 ollama（Metal 加速）；后期全容器化时 ollama 自动随 compose 起，二选一均可（容器内无 Metal，速度约一半，届时按需选择）。

## 四、成本与切换预案

| 场景 | 动作 | 成本 |
|------|------|------|
| Agnes 免费额度充足 | 默认使用（env 指向 Agnes） | 0 元 |
| Agnes 限流/停止免费 | `.env` 切到 Ollama（§2.3），重启后端 | 0 元（本地） |
| 两者都不可用 | 可再接入智谱 GLM-4-Flash 免费 / Gemini 免费 tier | 0 元 |

**验收**：切换后重新生成一条内容（`POST /api/content/generate` 跑通），确认新模型生效、输出质量可接受。
