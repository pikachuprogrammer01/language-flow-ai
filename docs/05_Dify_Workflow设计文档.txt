Dify Workflow 节点设计方案 V2
================================

零、Workflow 概述

本方案将内容生产拆为两个独立的 Dify Workflow：

  Workflow A「内容生成」  三个模板各一个，负责 AI 生成 + 词汇校验 → 输出 partial_dto
  Workflow B「媒体生产」  共用一个，接收 partial_dto → TTS → 视频渲染 → 输出 final_dto

MVP 阶段两个 Workflow 自动串联（A 的输出直接喂给 B）。
后续接入人工审核时，只需在 A 和 B 之间插入审核环节，Workflow 本身无需修改。

二、全局约定

2.1 节点命名规范

| 节点类型            | 命名格式              | 示例                      |
| ------------------- | --------------------- | ------------------------- |
| Start               | start                 | start                     |
| LLM                 | llm_<功能>            | llm_generate_story        |
| Code                | code_<功能>           | code_validate_words       |
| HTTP Request        | http_<功能>           | http_query_cet_db         |
| End                 | end                   | end                       |

2.2 变量命名规范

Dify 中每个节点的输出作为一个变量，下游节点通过变量名引用：

| 变量名               | 所属 Workflow | 来源节点             | 说明                           |
| -------------------- | ------------- | -------------------- | ------------------------------ |
| user_input           | A             | start                | 用户原始输入                     |
| story_result         | A             | llm_generate_story   | AI 生成的故事文本 + 候选词       |
| extracted_words      | A             | code_extract_words   | 去重后的候选词列表               |
| cet_result           | A             | http_query_cet_db    | 词库校验结果（scene_word用）      |
| validated_content    | A             | code_validate_words  | 校验后的 content + words        |
| cet_words            | A             | http_query_cet_db    | 词库随机抽取结果（word_card/quiz用）|
| quiz_result          | A             | llm_generate_quiz    | AI 生成的选择题                 |
| card_result          | A             | llm_generate_cards   | AI 生成的单词卡片               |
| partial_dto          | A → B        | A:code_assemble_dto  | 含 id+createdAt，不含 audio/video|
| partial_dto          | B             | B:start              | 接收自 Workflow A，透传给下游     |
| tts_result           | B             | http_tts             | TTS 返回的音频信息              |
| dto_with_audio       | B             | code_merge_audio     | 含 audio 的半成品 DTO           |
| video_result         | B             | http_render_video    | 视频渲染返回的视频信息           |
| final_dto            | B             | code_merge_video     | 完整的 ContentDTO               |

2.3 状态变更时机

Workflow A（内容生成）:
  draft (start) → ai_generating (LLM) → content_ready (code_assemble_dto)

  ※ draft 和 ai_generating 是 Workflow A 启动后、DTO 尚未创建时的前置状态。
     ContentDTO 从 code_assemble_dto 节点开始承载，初始值为 "content_ready"。

Workflow B（媒体生产）:
  content_ready (start, 接收 A 的输出)
    → tts_processing (TTS 调用中)
    → audio_ready (TTS 完成)
    → video_rendering (视频渲染中)
    → completed (视频渲染完成)

任何 HTTP 节点异常时 → failed（由 Dify 错误处理分支设置，本文档不展开）


三、Workflow A1：情景背词 (scene_word) 内容生成

3.1 流程图

start
  │  { topic, level, wordCount, targetDuration, voice?, style? }
  ▼
llm_generate_story
  │  根据主题生成中英混合故事
  │  输出: { title, segments: [{ text, candidateWords: [{ word, wordIndex }] }] }
  ▼
code_extract_words
  │  从 segments 中提取所有候选词（去重）
  │  输出: { candidateWords: [{ word, wordIndex, segmentIndex }] }
  ▼
http_query_cet_db
  │  用候选词列表查询四六级词库
  │  输出: { matchedWords: [{ word, level, meaning, frequency }], unmatchedWords: [string] }
  ▼
code_validate_words
  │  只保留在词库中匹配成功的词，将 WordInfo 填回对应 segment
  │  输出: { content: SceneWordSegment[], words: WordInfo[] }
  ▼
code_assemble_dto
  │  生成 id + createdAt，组装 partial_dto（status="content_ready"）
  │  输出: partial_dto
  ▼
end
  │  输出 partial_dto，供 Workflow B 消费

-----------------------------------------------------------------
节点 3: code_extract_words
----------------------------------------------------------------
类型: Code (TypeScript)
输入变量: story_result
作用: 遍历所有 segments，提取 candidateWords 并去重，为下一步词库查询做准备

代码:

  interface SegmentInput {
    text: string;
    candidateWords: { word: string; wordIndex: number }[];
  }

  function main(story_result: { title: string; segments: SegmentInput[] }) {
      const seen = new Set<string>();
      const candidates: { word: string; wordIndex: number; segmentIndex: number }[] = [];
      (story_result.segments || []).forEach((seg, si) => {
          (seg.candidateWords || []).forEach(cw => {
              const w = (cw.word || "").toLowerCase().trim();
              if (w && !seen.has(w)) {
                  seen.add(w);
                  candidates.push({
                      word: w,
                      wordIndex: cw.wordIndex || 0,
                      segmentIndex: si
                  });
              }
          });
      });
      return {
          candidateWords: candidates,
          // 纯单词数组，供 http_query_cet_db 的请求体直接使用（validate-words 接收 string[]）
          wordList: candidates.map(c => c.word),
          title: story_result.title || ""
      };
  }

输出变量名: extracted_words（包含 candidateWords 数组、wordList 和 title）

-----------------------------------------------------------------
节点 5: code_validate_words
----------------------------------------------------------------
类型: Code (TypeScript)
输入变量: story_result, cet_result
作用: 将词库校验通过的词汇回填到对应 segment，构建 SceneWordSegment[] 和汇总 WordInfo[]

代码:

  interface MatchedWord {
    word: string; level: string; meaning: string; frequency?: number;
  }

  function main(story_result: { segments: SegmentInput[] },
                cet_result: { matchedWords: MatchedWord[] }) {
      const cetMap = new Map<string, MatchedWord>();
      (cet_result.matchedWords || []).forEach(mw => {
          cetMap.set(mw.word.toLowerCase(), mw);
      });

      const content: { text: string; words: Record<string, unknown>[] }[] = [];
      const allWords: Record<string, unknown>[] = [];
      const seenWord = new Set<string>();

      (story_result.segments || []).forEach(seg => {
          const segWords: Record<string, unknown>[] = [];
          (seg.candidateWords || []).forEach(cw => {
              const w = (cw.word || "").toLowerCase().trim();
              const info = cetMap.get(w);
              if (info) {
                  segWords.push({
                      word: info.word, meaning: info.meaning, level: info.level,
                      wordIndex: cw.wordIndex || 0, frequency: info.frequency
                  });
                  if (!seenWord.has(w)) {
                      seenWord.add(w);
                      allWords.push({
                          word: info.word, meaning: info.meaning,
                          level: info.level, frequency: info.frequency
                      });
                  }
              }
          });
          // 该段所有候选词均未通过词库校验 → 整段丢弃（SPEC §6.2.6）
          if (segWords.length === 0) return;
          content.push({ text: seg.text, words: segWords });
      });

      return { content, words: allWords };
  }

输出变量名: validated_content（包含 content: SceneWordSegment[] 和 words: WordInfo[]）

节点 6: code_assemble_dto
----------------------------------------------------------------
类型: Code (TypeScript)
输入变量: user_input, story_result, validated_content
作用: 生成 id + createdAt，组装完整的 partial_dto

代码:

  function main(user_input: Record<string, unknown>,
                story_result: { title: string },
                validated_content: { content: unknown[]; words: unknown[] }) {
      const now = new Date().toISOString();
      const dateStr = new Date().toISOString().slice(0, 10).replace(/-/g, "");
      const hexId = Math.random().toString(16).slice(2, 8);
      return {
          id: `cnt_${dateStr}_${hexId}`,
          template: "scene_word",
          title: story_result.title || "",
          level: (user_input.level as string) || "",
          targetDuration: (user_input.targetDuration as number) || 60,
          content: validated_content.content || [],
          words: validated_content.words || [],
          style: user_input.style || { background: "white" },
          voice: user_input.voice || { id: "female_01", speed: 1.0 },
          status: "content_ready",
          createdAt: now,
          updatedAt: now
      };
  }

输出变量名: partial_dto

说明: id 和 createdAt 在 Dify 内部生成，保证全流程可追踪。
      voice 和 style 有默认值，用户不传也能跑通。

代码:

  function main(user_input: Record<string, unknown>,
                quiz_result: { title: string; questions: { word: { word: string; meaning: string; level: string }; stem: string; options: string[]; correctIndex: number; explanation: string }[] }) {
      const now = new Date().toISOString();
      const dateStr = new Date().toISOString().slice(0, 10).replace(/-/g, "");
      const hexId = Math.random().toString(16).slice(2, 8);
      const seen = new Set<string>();
      const words: { word: string; meaning: string; level: string }[] = [];
      (quiz_result.questions || []).forEach(q => {
          const w = q.word;
          const key = (w.word || "").toLowerCase();
          if (key && !seen.has(key)) {
              seen.add(key);
              words.push({ word: w.word, meaning: w.meaning, level: w.level });
          }
      });
      return {
          id: `cnt_${dateStr}_${hexId}`,
          template: "quiz",
          title: quiz_result.title || "",
          level: (user_input.level as string) || "",
          targetDuration: (user_input.targetDuration as number) || 30,
          content: quiz_result.questions || [],
          words,
          style: user_input.style || { background: "white" },
          voice: user_input.voice || { id: "female_01", speed: 1.0 },
          status: "content_ready",
          createdAt: now,
          updatedAt: now
      };
  }

七、外部服务 API 契约

Dify 通过 HTTP Request 节点调用的后端服务需要实现以下接口：

7.1 四六级词库服务

  POST /api/cet/validate-words
    输入: { "words": ["contract", "continent"], "level": "CET4" }
    输出: { "matchedWords": [...], "unmatchedWords": [...] }

  POST /api/cet/random-words
    输入: { "level": "CET4", "count": 10 }
    输出: { "words": [{ "word", "level", "meaning", "frequency" }] }

7.2 TTS 服务

  POST /api/tts/generate
    输入: { "content": ContentArray, "template": string, "voice": VoiceConfig }
    输出: { "audio": { "url", "duration", "format" } }
    说明: 后端负责将 ContentArray 转为适合朗读的纯文本

7.3 视频渲染服务

  POST /api/video/render
    输入: ContentDTO (含 audio)
    输出: { "video": { "url", "duration", "resolution", "format", "size" } }


八、Dify 项目中的文件组织建议

在 Dify 中建议按以下方式组织（Dify DSL 导出后）：

  dify/
  ├── content_generation/
  │   ├── scene_word.yml       # Workflow A1：情景背词 内容生成
  │   ├── word_card.yml         # Workflow A2：单词卡片 内容生成
  │   └── quiz.yml              # Workflow A3：选择题 内容生成
  └── media_production/
      └── media_production.yml  # Workflow B：媒体生产（TTS + 视频）

说明: 三个内容生成 Workflow 可以独立触发；媒体生产 Workflow 接收它们的输出。
      MVP 阶段由调用方串联：先调 A，拿到 partial_dto 再调 B。
      后续如果 Dify 支持子 Workflow 调用，可直接在 A 末尾串 B。

十、与 ContentDTO 文档的关系

本文档与 04_Content_DTO设计文档.txt 的关系：

  04_文档 定义数据结构（What）
  05_文档 定义构建流程（How）

  04_文档中的 ContentDTO 接口 = 本方案 Workflow B final_dto 的结构
  04_文档中的 Request DTO  = 本方案 Workflow A start 节点的输入
  04_文档中的 Response DTO = 本方案 Workflow B end 节点的输出

  Workflow A 的输出 partial_dto 是 ContentDTO 的"半成品"（缺 audio/video），
  Workflow B 消费它并补全为 final_dto。
