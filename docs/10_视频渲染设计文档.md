## 一、目标

将 `ContentDTO`（含 `audio`）渲染为 **9:16（1080×1920）MP4 短视频**：
静态画面逐帧截图 + 音频合成。MVP 不做动画，靠**字幕分段切换 + 配音**呈现节奏。

技术选型（SPEC §2.2 硬约束）：**Playwright（截图） + FFmpeg（合成）**，
禁止 Puppeteer（darwin/arm64 场景可换，但当前栈为 Playwright）。

---

## 二、调用链

```
Dify Workflow B → POST /api/video/render（请求体 = 完整 ContentDTO + audio）
        │
        ▼
routes/video.ts（Zod 校验 ContentDTO 必填字段）
        │
        ▼
services/video.service.ts
        │  1. 按 template 选择 Renderer（isSceneWord / isWordCard / isQuiz）
        │  2. Renderer.render(dto) → 帧截图列表（PNG, 1080×1920）
        │  3. 合成时序：audio.duration → 每帧停留时长
        │  4. FFmpeg：PNG 序列 + TTS 音频 → MP4（MVP 静音，无 BGM）
        ▼
packages/backend/uploads/video/{uuid}.mp4
        │
        ▼
响应 { video: { url, duration, resolution: "1080x1920", format: "mp4", size } }
```

## 三、TemplateRenderer 接口（`renderer/renderer.interface.ts`）

```typescript
export interface RenderFrame {
  /** 帧的 HTML 内容或截图文件路径 */
  filePath: string;       // /tmp/language-flow-render/{taskId}/frame-0001.png
  /** 该帧在视频中的停留时长（秒） */
  duration: number;
}

export interface RenderResult {
  frames: RenderFrame[];
  totalDuration: number;  // = audio.duration（对齐配音）
}

export interface TemplateRenderer {
  render(dto: ContentDTO, workDir: string): Promise<RenderResult>;
}
```

- `render` 返回**帧列表 + 每帧时长**，由 service 统一交给 FFmpeg
- 三个实现：`scene-word.renderer.ts` / `word-card.renderer.ts` / `quiz.renderer.ts`
- 各 Renderer 只负责「HTML 模板渲染 + 截图」，不碰音频/合成

## 四、HTML 模板规范

模板文件放 `packages/backend/src/renderer/templates/{template}.html`（Node 内嵌或 `readFile` 加载）。

### 4.1 通用规格

| 项 | 规格 |
|----|------|
| 画布 | 1080×1920（9:16），`<body>` 无滚动条，`overflow: hidden` |
| 背景 | **纯白**（`background: #ffffff`，当前阶段固定；预留 `style.background` 扩展） |
| 字体 | 系统字体栈：`"PingFang SC", "Microsoft YaHei", sans-serif`；英文用 `Georgia / Times` 类衬线 |
| 注入方式 | Playwright `setContent(html)`，数据由 Renderer 拼进 HTML（`{{VALUE}}` 占位或字符串模板） |
| 截图像素 | `deviceScaleFactor: 1`，viewport 1080×1920，`type: "png"` |

### 4.2 scene_word（情景背词）

依据《情景词汇阅读视频模板设计规范 V1.0》：
- 顶部：标题栏（视频标题，32-40px，加粗）
- 中部：中英混合文本（36-48px，行高 1.6），**四六级词汇高亮**（`<mark>` 样式：橙色底/粗体）
- 底部：当前 segment 词汇释义条（`word — meaning`，28px，白字深色条或描边）
- 每 segment 一帧；帧时长 = 该段文本朗读时长

### 4.3 word_card（单词卡片）

依据《四级词汇情景记忆卡片设计方案》（**仅采用文字排版规格**，背景统一纯白，见该文档顶部 MVP 说明）：
- 居中卡片（圆角、阴影、留白 120px 边距）
- 单词（64-80px 加粗）→ 词性（32px 灰色）→ 释义（40px）→ 例句（36px）→ 例句翻译（32px 灰色）
- 每张卡一帧

### 4.4 quiz（选择题）

- 题干（44px）+ 4 选项（36px，A/B/C/D 编号）
- 解析帧：题干 + 正确选项高亮（绿色）+ 解析文字（32px）
- 每道题 2 帧：题目帧 + 解析帧

## 五、Playwright 截图流程

```
1. 每个任务创建独立工作目录：{RENDER_TEMP_DIR}/{taskId}/（默认 /tmp/language-flow-render）
2. 无头浏览器：chromium.launch({ headless: true })（首次运行自动下载 Chromium）
3. 对每个 content 单元（segment/card/question）：
   a. page.setViewportSize({ width: 1080, height: 1920 })
   b. page.setContent(renderHtml(unit))
   c. page.screenshot({ path: `${workDir}/frame-${String(i).padStart(4, "0")}.png`, type: "png" })
4. 释放浏览器，返回帧列表
```

**帧时长分配（关键设计）**：
- 总时长 = `audio.duration`（以 TTS 实际时长为准，保证声画同步）
- 逐段分配：按每个 segment 文本字符数占比 × 总时长（中文 1 字 ≈ 0.35s 朗读，可作校验参考）
- 最后一段时长 = 总时长 − 前段之和（吸收舍入误差，保证总长精确）

## 六、FFmpeg 合成

**命令模板**（帧序列 + 音频 → MP4，H.264 + AAC）：

```bash
ffmpeg -y \
  -framerate 1 -i frame-%04d.png \
  -i {audio}.mp3 \
  -vf "scale=1080:1920,format=yuv420p" \
  -c:v libx264 -preset medium -crf 23 \
  -c:a aac -b:a 128k \
  -shortest \
  {output}.mp4
```

- `-framerate 1`：每帧 1 秒基础速率，时长控制靠 **每帧重复 N 次**（`-framerate 1` + 重复帧）或 concat 滤镜逐帧指定时长（更精确，推荐 concat demuxer 方案）
- **精确方案（推荐）**：每帧按 `duration` 生成 `frame-{i}.ts`（`-f lavfi -i color` 或 concat 文本）→ concat 后合成音频。实现时二选一，**以声画同步为验收标准**
- BGM：可选（MVP 静音合成，见 docs/03 模块 9；扩展时 `-stream_loop -1 -i bgm.mp3 -filter_complex amix`，音量 -20dB 低于人声）
- 输出：`uploads/video/{uuid}.mp4`，1080×1920，H.264 + AAC，`-movflags +faststart`

## 七、错误处理与状态流转

| 场景 | 行为 |
|------|------|
| ContentDTO 缺必填字段 / template 非法 | 400（Zod 校验） |
| Playwright 启动失败 / 截图失败 | 500，清理临时目录 |
| FFmpeg 合成失败 | 500，**删除半成品 MP4**，不保留 |
| 业务侧（任务流程） | 状态置 `"failed"`（AGENTS.md §3.4：不保留半成品） |

临时目录清理：`finally` 中 `rm(workDir, { recursive: true, force: true })`；
产物仅保留最终 `uploads/video/{uuid}.mp4`。

## 九、已知限制与升级路径（ponytail: 上限标注）

- 纯静态帧 + 无动画 → 升级路径：CSS 过渡/关键帧动画（Playwright 连拍）、动态背景
- 字体依赖系统字体 → 升级路径：打包 WebFont 进模板
- `RENDER_TEMP_DIR` 默认 /tmp，需保证磁盘空间（单视频 ≈ 50-100MB 帧图）
- Chromium 需在部署环境安装（CI/服务器 `playwright install chromium --with-deps`）
