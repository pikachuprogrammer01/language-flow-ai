## 二、表结构（已建，勿改）

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | int PK auto_increment | 自增主键 |
| `word` | varchar(100) NOT NULL | 英文单词（小写存储） |
| `meaning` | varchar(500) NOT NULL | 中文释义，可含多个义项（分号分隔） |
| `level` | enum('CET4','CET6') NOT NULL | 词汇等级 |
| `frequency` | float DEFAULT 0 | 词频，**0~1 比例**（SPEC §5.1.1 示例 0.85） |

索引：`idx_level_freq(level, frequency)`——random-words 按等级抽词 + 词频排序会用到。

## 三、数据来源方案

按优先级推荐（**需你确认取数渠道后执行**）：

### 方案 A：公开开源词库（推荐）
- 来源：GitHub 开源 CET4/CET6 词库（如「qwerty-learner」词库、`english-vocabulary` 类项目），或考纲词表整理版
- 格式多为 JSON/CSV（word + meaning + level），需小脚本清洗为下方标准 CSV
- 优点：量大（CET4 约 4500 词 / CET6 约 5500 词）、含等级天然匹配本表
- 缺点：释义质量参差，需抽查清洗

### 方案 B：人工整理 CSV
- 自己按考纲词表手工整理（如《四级词汇闪过》等），导出标准 CSV
- 优点：释义可控、贴合教学语境；缺点：工作量大，起步慢

### 方案 C：LLM 辅助生成
- 用 LLM 按考纲批量生成 word/meaning/level 后人工抽检
- 优点：快；缺点：准确性需严格抽检，**不推荐作为唯一来源**

> **默认推荐方案 A**：先找开源词库落地（数量优先），后续用人工/LLM 补充释义质量。
> 若你已有词库文件，直接按 §四 格式整理即可。

## 四、标准数据格式（CSV）

```csv
word,meaning,level,frequency
contract,合同；契约,CET4,0.85
continent,大陆；洲,CET4,0.72
elaborate,精心制作的；详尽的,CET6,0.31
```

| 列 | 规则 |
|----|------|
| word | 小写，去重（唯一键），不做大小写变体 |
| meaning | 中文释义，多义项用中文分号 `；` 分隔 |
| level | 仅 `CET4` / `CET6` |
| frequency | 0~1 浮点；无数据时留空（导入后为 0） |

文件放 `packages/backend/seed-data/cet_words.csv`（目录随 seed 脚本一起建，`seed-data/` 不 gitignore，可提交共享）。

## 五、Seed 脚本设计

`packages/backend/src/db/seed.ts`（待实现）+ `package.json` 增加：

```json
"db:seed": "tsx src/db/seed.ts"
```

行为约定：

1. 读取 `seed-data/cet_words.csv`（`node:fs` + 简单 split 解析，**不引入 csv 依赖**）
2. 校验：word 非空、level ∈ {CET4, CET6}、meaning 非空，非法行跳过并计数
3. 幂等：先 `DELETE FROM cet_words`（全量重灌）再 `INSERT`（分批，每批 500 行）
4. 完成后打印统计：`imported= N, skipped= M, total=N`
5. 运行方式：
   ```bash
   DATABASE_URL="mysql://dev:dev@localhost:3306/language_flow" pnpm --filter backend db:seed
   ```

> 全量重灌（而非 upsert）保证幂等与数据一致性；MVP 词库数据量 < 1 万行，重灌秒级完成。

## 六、接口行为约定（与 SPEC §5.1 对齐）

### validate-words
- 精确匹配：`word` 小写精确相等 + `level` 相等（Drizzle `inArray` + `eq`）
- 候选词去重；matched 保持输入顺序
- 全部 unmatched 也返回 200

### random-words
- 入参 `{ level, count(1~15) }`；按 `level` 过滤，**词频降序 + 随机偏移** 取词
  （实现建议：`ORDER BY frequency DESC` 取前 200 高频池，再随机取 count 个，兼顾质量与多样性）
- 词库不足时返回少于 count 个（200）
- 需要频率数据支撑：若 frequency 全为 0，退化为纯随机

## 七、数据质量要求

- [ ] word 全小写、无空格、无重复
- [ ] meaning 为中文，无英文残留（专有名词除外）
- [ ] CET4 词不出现 CET6 词表中（等级归属正确）
- [ ] 抽查 50 条释义人工核对
- [ ] 总量：CET4 ≥ 3000、CET6 ≥ 3000（MVP 下限）

---

## 八、验收标准

- [ ] `db:seed` 执行后 `cet_words` 行数 > 6000
- [ ] `validate-words` 对词库内单词返回 matched（含 meaning/frequency）
- [ ] `random-words` 返回 count 个词且等级正确
- [ ] seed 脚本可重复执行（幂等）
