> ① 缺少"定向注入"步骤（渲染器高亮要求英文词必须在 text 内）；
> ② 未处理词数下限（用户期望 8 起，共用常量不能直接改）；
> ③ 词表策略已改为混合词表（保留主题词）。
> 最新实施方案见 `问题解决方案.md` V2。

## 一、你的质疑

我之前说"LLM 写英文故事"，你问"全部英文谁来翻译"——你说得对，这个项目是给中国学生学英语用的，故事必须是中文的，不能本末倒置。

## 二、修正后的流程

```
保持：LLM 写中文故事（面向中国学生）
改变：候选池从"死列表 + 小池子"改为"随机大池 + LLM 自主选词标注"
```

### 旧流程（问题所在）

```
1. fetchTopicWords → LLM 列 15 个主题词
2. + NARRATIVE_WORDS（20个死列表）→ 候选池
3. + 高频池随机补 → 候选池（最多 20 个）
4. LLM 按候选池写中文故事
5. injectFromDict 扫描中文释义 → 替换为英文词
```

**问题**：候选池最多 20 个词，其中 20 个是固定的 NARRATIVE_WORDS，每次生成都一样。

### 新流程

```
1. randomWords(level, 150) → 从词库随机取 150 个词（每次不同，不固定）
2. LLM 按这 150 个词的中文释义写中文故事
3. LLM 在输出中明确标注用到了哪些英文词（words 数组）
4. validateAndFilter → 查词库校验 LLM 标注的词
5. acceptOutput → 验收主题 + 词数
```

**关键差异**：

| | 旧 | 新 |
|---|-----|-----|
| 候选池来源 | 主题词 + 死列表 + 高频池 | 纯随机 150 个词 |
| 候选池大小 | 最多 20 | 150 |
| 英文词来源 | 代码扫描中文释义替换 | LLM 自主选词 + 标注 |
| 固定程度 | NARRATIVE_WORDS 死列表 | 每次随机，不重复 |

## 三、Prompt 设计

### 核心 prompt

```
你是英语学习内容创作者。为 CET4 级别制作情景背词短视频。

【主题】{topic}

【要求】
1. 写一个中文情景故事，情节连贯、生活化，标题也用中文
2. 故事中自然使用下方词表里单词的中文含义（如词表里有"市场"，故事里就写"市场""行情"）
3. 对故事里用到的词表单词，在 segments 的 words 数组里列出对应的英文单词
4. 正文分 {segments} 段，每段 60-120 字
5. 至少用 5 个词表里的词，最多 20 个
6. 只输出一个 JSON 对象，不要任何其他文字

【词表】（共 150 个 CET4 单词，故事里用到的词必须来自此表）
{wordList}

【输出格式】
{{"title":"森林探险","topic":"{topic}","segments":[
  {"text":"Leo去森林探险，发现了一条小路。","words":["adventure","path"]}
]}}

【示例】（内容不可复用）
{{"title":"职场新人","topic":"职场故事","segments":[
  {"text":"Leo第一天上班，公司很大。","words":["company"]}
]}}
```

## 四、单词数量控制

| 场景 | 处理 | 反馈给 LLM |
|------|------|-----------|
| 0 个词 | 拒绝重试 | "故事中没有使用词表中的任何单词，请至少用 5 个" |
| 1-4 个词 | 拒绝重试 | "只用了 {N} 个词表单词，需要至少 5 个" |
| 5-20 个词 | 通过 | - |
| 21+ 个词 | 通过，保留前 20 | - |

超过 20 个时不截断单词本身，而是按文本出现顺序保留前 20 个。

## 五、单词与文案关联

- LLM 在写故事时就看到 150 个词的中文释义，自己决定哪些适合用
- LLM 在 words 数组中标注用到的词
- `validateAndFilter` 做两层校验：
  1. words 数组里的词必须在词库里（不在的剔除）
  2. 从 text 中提取英文词（防止 LLM 漏标），补进 words
- 如果 LLM 标注的词不在故事里（漏标），这些词被剔除

## 六、重试机制

### 4 种拒绝原因

| # | 条件 | 反馈 |
|---|------|------|
| 1 | JSON 解析失败 | "输出不是合法 JSON" |
| 2 | topic 偏离 | "主题偏离：要求围绕「X」，你输出的是「Y」" |
| 3 | 有效词 < 5 | "只用了 {N} 个词表中的词，需要至少 5 个。请检查故事里是否自然嵌入了词表单词的中文释义" |
| 4 | 有效词 = 0 | "故事中没有使用任何词表单词，请从词表中选择合适的词嵌入故事" |

每次重试重新随机取 150 个词，避免 LLM 记住旧词表。
