# 问题 1 详细方案：英文词少且重复

> ⚠️ **已废弃（2026-08-23）**：本文档的"LLM 写英文故事"方向已被否定（产品面向中国学生，故事必须中文）。
> 最新实施方案见 `问题解决方案.md` V2（中文故事 + LLM 标注 + 代码定向注入）。

## 一、当前流程与问题

```
当前流程：
1. fetchTopicWords → LLM 列 15 个主题相关词
2. + NARRATIVE_WORDS（20个死列表）→ 候选池
3. + 高频池随机补足 → 候选池
4. LLM 写纯中文故事
5. injectFromDict → 扫描中文释义，替换为英文词
6. acceptOutput → 验收

问题：
- NARRATIVE_WORDS 是死列表，product/market 每次必出现
- 候选池最多 20 个词，LLM 只能从里面选
- 注入依赖中文释义精确匹配，匹配不到就丢
```

## 二、新流程设计

```
新流程：
1. randomWords(level, 120) → 从词库随机取 120 个词（每次不同）
2. LLM 写英文故事 + 标注用到的英文词（segments.words）
3. validateAndFilter → 查词库校验，不在的剔除
4. acceptOutput → 验收（主题 + 词数）
5. 不通过 → 携带具体原因重试
```

## 三、Prompt 设计

### 第一次生成（无反馈）

```

【主题】{topic}

【要求】
1. 用英文写一个简短故事，句型简单，适合四级学习者

3. 故事中自然嵌入 8-20 个单词，这些单词必须来自下方词表
4. 正文分 {segments} 段，每段 60-120 字符

6. 只输出一个 JSON 对象，不要任何其他文字、不要 markdown 围栏

【词表】（共 120 个 CET4 单词，故事用到的词必须来自此表）
```

## 四、单词数量控制

### 目标范围
- 用户期望：8-20 个
- 硬约束：MIN_WORDS_PER_CONTENT = 5，MAX_WORDS_PER_CONTENT = 20

### 控制策略

| 场景 | 处理 |
|------|------|
| LLM 输出 0 个词 | 拒绝，反馈"故事中没有找到任何词表中的单词" |
| 1-4 个词 | 拒绝，反馈"只有 X 个有效词，需要至少 5 个" |
| 5-20 个词 | 通过 |
| 21-30 个词 | 通过，但保留前 20 个（按出现顺序） |
| 31+ 个词 | 通过，保留前 20 个 |

### 超过 20 个怎么办

**不截断单词本身**（截断会丢失信息），而是限制最终保留数量：

```ts
// 在 acceptOutput 之后，构造返回值之前
if (allWords.length > MAX_WORDS_PER_CONTENT) {
  // 按单词在文本中首次出现的顺序，保留前 20 个
  const wordOrder = [...new Set(
    filtered.flatMap((s) => extractEnglishWords(s.text))
  )];
  allWords = allWords.filter((w) => 
    wordOrder.some((wo) => wo.toLowerCase() === w.word.toLowerCase())
  ).slice(0, MAX_WORDS_PER_CONTENT);
}
```

## 五、单词与文案的关联

### 保证机制

1. **LLM 自主选择**：不是代码事后注入，而是 LLM 在写故事时自己决定用哪些词
2. **words 数组必须与 text 一致**：`validateAndFilter` 会从 `text` 中提取英文词，与 `words` 数组合并，确保两者不矛盾
3. **词库把关**：不在词库的词一律剔除，保证质量

### 如果 LLM 用了词但没写进 words 数组

`validateAndFilter` 会从 `text` 中提取英文词，自动补进 `words`。

### 如果 LLM 在 words 数组里列了词但 text 里没有

这些词会被剔除（因为不在 text 中，提取不到），反馈给 LLM 下次注意。

## 六、重试机制

### 重试条件（3 次上限）

| # | 条件 | 反馈给 LLM |
|---|------|-----------|
| 1 | JSON 解析失败 | "输出不是合法 JSON，必须只输出一个 JSON 对象" |
| 2 | topic 偏离 | "主题偏离：要求围绕「X」，你输出的主题是「Y」" |
| 3 | 有效词 < 5 | "有效词不足：过滤后只剩 N 个词库中的词，需要至少 5 个。请确保故事用的词都在词表里" |
| 4 | 有效词 = 0 | "故事中没有使用任何词表中的单词，请从词表中选择单词嵌入故事" |

### 重试 Prompt 变化

每次重试都重新随机取 120 个词（不重复），避免 LLM 记住上次的词表。

### 3 次都失败

抛出 `Error("内容生成未通过验收：{lastFeedback}")`，前端展示具体原因给用户。
